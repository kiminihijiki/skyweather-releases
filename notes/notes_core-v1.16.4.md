# SkyWeather Core 1.16.4（初回公開）

VRChat ワールド向けの空と天気のシステム「SkyWeather」の土台です（無料）。

## できること
- 大気の散乱による空の色と地平線のかすみ、太陽と月
- 一年を通して流れながら形を変える低い雲と、地面に落ちる雲の影
- 雲や空に合わせて色が変わる Lit シェーダー、Unity のフォグ連動、反射プローブの明るさ補正
- セットアップウィンドウ（設置・アップグレード・古いファイルの掃除・更新の確認）、プレビューウィンドウ、ワールド内の操作パネル

時刻・天気・季節はインスペクターで選んだ状態に固定されます。時間の流れ・天候の変化・季節の移り変わり・環境音は、別売りの各パッケージで追加できます。

## 動作環境
- Unity 2022.3 / VRChat SDK3 Worlds（UdonSharp 1.x）

タグ: `core-v1.16.4`
